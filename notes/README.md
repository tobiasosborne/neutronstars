# notes/

Session-scoped engineering notes. The repo's two stable top-level docs are
[`README.md`](../README.md) (GitHub landing) and [`CLAUDE.md`](../CLAUDE.md)
(project spec / AI onboarding); everything in this directory is more
volatile.

## Files

- **`HANDOFF.md`** — current session-end handoff. Rewritten or appended
  each session; the latest is always the most authoritative.
- **`decisions.md`** — append-only ADR-style decision log (D1, D2, …).
- **`approximations.md`** — master list of named approximations with
  validity, source, and impact estimates.
- **`failures.md`** — append-only failure post-mortems (F1, F2, …).

The verification log (`verification/VERIFICATION_LOG.md`) lives next to
the verification scripts it documents.
